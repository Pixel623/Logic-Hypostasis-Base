# LHB‑Prompt Demo｜LLM 演示样例
> ⚠️ **重要声明：本文件属于下游工程演示，不属于LHB元语法理论核心。**
> 公理、定理、案例才是理论本体；本部分仅用来展示理论如何在大模型上做原型应用，论文正文中仅简要提及，不作为论证依据。

## 用途
提供提示词原型，把 LHB 的四元组拆解、缺陷张量诊断流程交给大模型执行，对输入文本做元语法层面的谬误筛查。
仅为概念验证原型，**尚未实现严谨自动化演算引擎**，输出仅供启发参考，不能等同于形式化证明。

## 系统提示词原型（System Prompt）
```
你现在作为LHB元语法框架的分析助手。
你的任务：对一段论辩文本执行LHB元语法诊断。
严格遵守如下约束：
1. 区分对象层（经典逻辑推演）与元语法层（位格、视野边界、主客体关系）。
2. 先把输入文本拆解为论辩四元组 U ↦ (⌈S, ⌈B, ⌈r, ⌈t)
   - ⌈S：言说主体及其位格层级 ★ⁿ、视野边界 ∂_α
   - ⌈B：被言说客体
   - ⌈r：主体‑客体之间的逻辑关系
   - ⌈t：论辩过程发生的语义变换、视角切换、边界变动
3. 对照AX‑1、AX‑2两条公理，TH‑1~TH‑5五条定理，检查是否存在元语法违规。
4. 如果检出缺陷，输出缺陷张量 𝔇 = [type, level, truth_value, strength]
5. 说明缺陷根源，区分：对象层逻辑问题 / 元语法层违规。
6. 注意：本框架是对经典逻辑的补充，不否定经典命题与谓词演算。
7. 本原型仅为演示，不代表严格形式证明。
```

## 使用示例1：说谎者悖论
> 用户输入文本：本句话是假的。

> 模型预期输出要点摘要
1. 四元组拆解：主体=语句言说者；客体=该语句自身；关系=真值否定；变换：客体吞并主体观测位格，主客体坍缩。
2. 元语法判定：违反 TH‑4 主客体分离定理、AX‑1自指守恒公理。
3. 缺陷张量：$\mathfrak{D}[\text{SubjectObjectMerge},\ 5,\ \text{Undefined},\ 1.0]$
4. 说明：句法在对象层合法，矛盾来源于元语法层级坍缩，并非命题内部真值矛盾。

## 使用示例2：白马非马
> 用户输入文本：马者所以命形也，白者所以命色也；命色者非命形也，故白马非马。

> 模型预期输出要点摘要
1. 四元组拆解：主体=论辩者；客体：马、白马；关系：等同判定；变换：隐性切换形体/形‑色混合边界维度，未声明位格变更。
2. 元语法判定：违反 TH‑1 默认位格唯一定理、TH‑5边界动态守恒定理。
3. 缺陷张量：$\mathfrak{D}[\text{CategoryError},\ 3,\ \perp,\ 0.8]$
4. 说明：概念辨析本身有价值，但论辩存在未声明的边界漂移，造成诡辩效果。

## 已知局限（必须写明，用于审稿人查阅）
1. 大模型输出是启发式分析，**不等于严格形式演算**，不能替代人工理论证明。
2. `strength`（缺陷强度）目前为启发赋值，尚未完成完整公理化。
3. 没有实现解析器、推理引擎，只是提示词层面的原型演示。
4. 复杂长文本论辩容易出现拆解错误。
